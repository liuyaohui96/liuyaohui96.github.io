## 单元格操作


1. 单元格选中：
    * enter/shift enter上下移动；tab/shift tab左右移动
    * 连续的单元格区域：
        * 通过鼠标拖拽，
        * 选择开始单元格然后按住shift选择最后单元格
    * 不连续单元格区域可以通过鼠标配合ctrl一起
    * 整行或者整列：点击行号列号，即可选中对应行列；通过鼠标拖动，或者配合ctrl/shift可以选择多行多列
    * 工作表区域左上方点击，选择整个单元格
    * ctrl + a选中有内容的单元格区域
    * ctrl + 方向键：快速跳转到当前行或者列对应方向位有数据的单元格，可以利用这个查看单元表的行列最大数目
    * ctrl + shift + 方向键，就是选中跳转过程的区域
 

2. 单元格移动
    * 指向单元格边缘，变成移动按钮，就可拖拽移动；同理，配合ctrl可以拖拽复制
    * 剪切粘贴ctrl x和ctrl v
    * 行列移动：选中行或者列，指向边缘，变为变成移动按钮，就可拖拽移动
    * 行列之间交换：鼠标拖拽过程中，按住shift就可以进行交换

3. 单元格插入
    * 插入单元格：右击插入，选择相应活动单元格右移或者下移
    * 插入行列：选中对应行列数目，右击插入，选择插入行或者列，就可以插入对应行列的数目


4. 单元格删除：
    * 删除单元格：右击删除，选择对应的右侧单元格左移”或“下方单元格上移“
    * 选中对应区域，右击删除，删除单元格或者行列

5. 合并/拆分单元格：开始选项卡，点击合并，有以下合并方式
    * 合并单元格：合并，不设置对齐方式
    * 合并后居中：合并，设置居中对齐
    * 拆分单元格：已经合并的单元格点击一下合并就拆分单元格了

6. 清除单元格
    * delete清除内容
    * 通过开始选项卡 - 编辑菜单 - 橡皮擦可以选择清除全部，清除内容，清除格式，清除批注，清除超链接


7. 调整单元格行高列宽：
    * 通过行号或者列号之间的十字拖动按钮拖动
    * 开始选项卡 - 单元格组 - 格式 -调整行高或者列宽，或者设置根据内容自动调整
    * 点击两下行号或者列号之间的十字拖动按钮就能自动调整行高列宽


8. 显示或者隐藏单元格：开始选项卡 - 单元格组 - 格式 - 显示或者隐藏；或者右键菜单实现

## 公式


1. 运算符的类型
    * 一般常见的程序语言的运算符
    * 文本运算符`&`：连接一个或者多个文本
    * 引用运算符：与单元格引用一起使用，包括
        * `,`：联合引用，引用多个或者多块区域，如比如`SUM(A1:A10,C1:C10)` 表示对这两个区域的数据进行求和计算
        * `:`: 区域引用，引用两个单元格之间的所有单元格，如`A1:A10`表示从 A1 到 A10 的单元格区域
        * 空格：交叉引用，比如 A1:B5 C3:D7，表示两个区域重叠部分的单元

2. 运算符优先级
    * `:`
    * 空格
    * `,`
    * 然后一般程序语言的运算符遵循常见规则

3. 括号：使用括号包围进行优先计算


4. 单元格引用
    * 单元格引用方法：输入`=`，然后输入单元格地址或者用鼠标选择
    * 单元格引用类型
        * 相对引用：直接使用列标和行号，如 A1、B2 等，在公式复制或填充到其他位置时，引用的单元格会相应变化
        * 绝对引用：在列标和行号前都加上`$`，如比如$A$1 就是绝对引用单元格A1
        * 混合引用：有两种情况，一种是列绝对、行相对，如$A1；另一种是行绝对、列相对，如 A$1


5. 数组公式：可以对一组或多组数据进行计算，并返回一个或多个结果，使用数组公式时
    * 需要在输入公式后按`Ctrl+Shift+Enter `组合键来确认，这样公式会被自动加上大括号“{}”，表示这是一个数组公式
    * 数组公式的数组维数需要相同，不匹配会自动扩展



6. 公式选项卡
    * 函数库
    * 定义名称
        * 新建名称：也可以通过直接编辑名称框编辑名称
        * 名称管理器：新建编辑删除名称
    * 审核
        * 追踪引用单元格：看到当前单元格被哪些单元格影响（引用单元格）
        * 追踪从属单元格：当前单元格会影响到哪些单元格（从属单元格），通过箭头进行显示
        * 移去箭头
        * 错误检查：可以帮助识别公式中可能出现的错误类型，并给出提示
        * 显示公式：直接在工作表中查看所有单元格中的公式，而不是显示公式的计算结果
        * 公式求值：可以逐步查看公式计算的过程和中间结果，便于理解复杂公式的运算逻辑


7. 函数基础
    * 基本形式：`=函数名(函数参数)`
    * 输入函数的方式
        * 公式 - 函数库 - 插入函数
        * 编辑框手动输入函数
    * 修改函数：编辑框修改，参数通过点击编辑框左边的函数按钮即可方便修改


8. 常用函数，见附录的函数类型


9. 其他操作

### 数据整理



1. 数据选项卡 - 获取外部数据

2. 数据选项卡 - 排序和筛选
    * 排序：
        * 升序
        * 降序
        * 自定义排序；自定义排序中，选择主要关键字（按哪一列排序）、排序依据（升序或降序）等。如果有多个条件，可以添加次要关键字
        * 编辑自定义排序列表：文件 - 选项 - 高级 - 在“常规”部分找到“编辑自定义列表”并点击进行编辑

    * 筛选：
        * 筛选数据”选项卡，点击“筛选”命令，此时标题行的每个字段名旁会出现下拉箭头，点击需要筛选的字段的下拉箭头，根据需求选择筛选条件，比如勾选特定值、文本筛选、数字筛选等。快捷键是`ctrl + shift + l`
        * 高级筛选：见下面高级筛选的步骤

3. 数据选项卡 - 数据工具 
    * 分列：将一个包含多种信息的文本字符串，根据特定的分隔符或固定宽度，拆分成多个独立的列
        * 分隔符类型：常见的分隔符有逗号、制表符、空格、分号等，也可以自定义分隔符
        * 固定宽度：制定位置分列
        * 列数据类型：可以指定每列的数据类型，如文本、数值、日期等
    * 删除重复项


4. 数据选项卡 - 分级显示 - 分类汇总：对数据按特定分类进行统计汇总，如求和、平均值、计数等
    * 前提条件：数据需要先按分类字段进行排序
    * 分类字段：决定数据如何分组的列
    * 汇总方式：包括求和、平均值、计数、最大值、最小值等多种方式
    * 汇总项：选择要进行汇总计算的具体字段
    * 分类汇总后会形成分级显示，可以展开或折叠不同级别来查看详细或汇总信息，除了点击分级显示里面的选项展开折叠，在表格左边也有枝干树折叠展开
    * 删除分类汇总：进入分类汇总并选择“全部删除”来删除

5. 数据选项卡 - 数据有效性：数据选项卡 - 数据工具 - 数据有效性，可以设置
    * 有效条件：数据类型，数据范围
    * 输入信息提示
    * 出错警告


6. 高级筛选步骤
    * 准备好数据列表和筛选条件区域，条件区域至少包含与数据列表相对应的列标题和具体条件
    * “数据”选项卡，点击“高级筛选”

### 财务函数



#### FV
FV 函数：用于根据固定的利率和付款期数，计算未来的终值
```
FV(rate, nper, pmt, [pv], [type])
```
* rate：各期利率
* nper：总期数
* pmt：每期付款额
* pv：现值（可选），如果省略，默认值为 0
* type：付款时间类型（0 或 1），0 表示期末付款，1 表示期初付款（可选），默认值为 0
* 要计算在年利率为 6%、期数为 5 年、每年付款 1000 元的情况下的未来值，可以使用以下公式：=FV(0.06, 5, -1000)


年金终值公式推导
```
年金终值公式的推导基于复利的概念。

假设每年支付的金额为A，年利率为r，期数为n

第一年的付款在经过n年后价值为A(1+r)^{n-1}

第二年的付款在经过n年后价值为A(1+r)^{n-2}

以此类推，第n年的付款在经过n年后价值为A(1+r)^{n-n} = A

将每年的付款价值相加，得到年金终值的表达式：

A(1+r)^{n-1} + A(1+r)^{n-2} +... + A

可以看成是有n项，首项是A，公比是1+r的等比数列求和

S = a1*(1-q^n)/1-q

代入得到

S = A * (1-(1+r)^{n})/1-(1+r)
   = A * (1+r)^{n}-1）/r

```
